# Uploads Directory Structure

- `releases/`: full setup executables, named `GTMC-NPI-Setup-vX.Y.Z.exe` (upload via FTP/SCP, not committed).
- `updates/`: lightweight update ZIP files, named `GTMC-NPI-Update-vX.Y.Z.zip`.
- `tickets/`: support-ticket attachments (private, served by staff/download-ticket-attachment.php).
- `payments/`: payment proofs uploaded from the portal (private, served by staff/payment-proof.php).
